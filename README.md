## About the model
This repository contains the AF teaching example from the Economic Evaluation Modelling short course
at University of Bristol medical school. This is Markov cost-effectiveness model comparing anticoagulant strategies for stroke prevention. 

The model itself is based on the AF model and network meta-analysis (NMA) described in:
- https://www.bmj.com/content/bmj/359/bmj.j5058.full.pdf 
- https://pmc.ncbi.nlm.nih.gov/articles/PMC6699015/

This model was later adapted for the NICE 2021 Guidelines on AF.
